# 头像绘制与动画约束

## 模块职责

- `avatar_character.dart`：稳定种子到轮廓、眼距、倾角等参数的映射，不依赖运行时字符串哈希。
- `avatar_character_painter.dart`：归一化路径、同色侧面、宽明暗过渡和胶囊眼；轮廓和色彩绘制资源有界缓存。
- `avatar_projection.dart`：根据视线控制量计算左右转头、上下俯仰及前后平面的透视矩阵；同一投影用于面部、眼睛和侧壁。
- `avatar_solid.dart`：连接投影轮廓的实体覆盖面与顶点色网格，前缘颜色与前脸衔接，后缘同色轻压暗。
- `blob_avatar.dart`：悬停区域、指针跟随、眨眼、按压、忙闲状态及群组合。
- `avatar_life.dart`：全局指针分发和视线阻尼纯函数。
- `avatar.dart`：兼容入口委托统一角色组件，保留名称语义与角标。

轮廓包含豆形、圆枕、卵石、胶囊、三瓣云、圆楔、软六边形和蛋形。配色使用主题中固定索引的九色板，头像与姓名保持同色身份。

## 尺寸与交互

- 实际最小入口为14px；胶囊头部22px的群成员也可能缩小至约14px。
- 小尺寸保持轮廓和双眼，不叠加嘴、配件或细碎高光。
- 主控身份环和显式角标独立于造型；符号角标只在足够大的主控头像显示。
- 群组合按成员去重，最多四人；空组和单成员居中，成员使用稳定键，禁用群成员指针跟随。
- `animate` 控制呼吸、眨眼与按压；静态头像仍可跟随指针，忙碌状态可使用间歇视线动作。
- 闲置六秒后停止动画；忙转闲重新安排休眠。身份、动画开关和指针开关变化须同步资源状态。
- 视线ticker到站停止并复用，销毁时统一释放；头像默认不拦截整行点击。
- 转头上限为左右34°、上下23°。透视变换同时驱动面部收窄、近远眼比例和可见侧面，正面姿态保持原造型。

## 绘制与性能

前后表面复用缓存渐变，侧壁使用一次顶点色网格绘制，无 `clipPath`、模糊或 `saveLayer`。几何缓存按轮廓种类固定，颜色缓存最多128项。转头时使用32个缓存轮廓采样点连接前后侧壁；前缘采样前脸颜色、后缘同色轻压暗，避免形成硬色片。矩阵与侧壁按当前角度计算，不积累角度缓存，临时Vertices用后释放。改变静态绘制参数后，应重新启动预览以刷新缓存。

性能对比须在同一设备、同一profile构建和相同活动头像数量下进行，报告样本数、raster均值/P90及超16ms帧。其它设备的历史帧耗时不能作为本机保证。

## 验证与预览

```bash
cd app
flutter test test/avatar_life_test.dart test/avatar_character_test.dart test/avatar_lifecycle_test.dart test/avatar_projection_test.dart test/avatar_solid_test.dart
flutter run -d macos -t tool/avatar_gallery.dart
```

独立预览只使用合成身份，不启动服务端或读取用户配置。验收覆盖14/16/22/46/96px、暗浅背景、群组合、忙闲和最大视线/按压姿态；同时检查身份更新、群成员重排、整行点击与动画资源释放。
