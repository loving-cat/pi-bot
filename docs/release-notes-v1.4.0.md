## 这一版做了什么

### 一台电脑上，人和 bot 同时干活

新增**独立桌面**（规格 §5.6 的 T1 档）：bot 在自己的那张桌面上开程序、截图、点按钮、打字，
**碰不到你正在用的窗口和鼠标**。所以你该怎么用电脑还怎么用，它同时在干活 —— 全双工，不是排队等你走开。

- 按部门分桌：同部门共用一张（轮流用，互相不踩），不同部门互相看不到对方的窗口；
- 浏览器会自动带上你的登录态（复制一份配置快照，7 天自动清，不会同步回本机，也可以关掉）；
- 截到全黑就报失败，不给你一张黑图；
- 同最多 4 张桌面，用完空闲 10 分钟自动收。

### 权限：Bot 可以申请，你一处点

- 主 Bot 或部门负责人可以**申请**权限（看屏幕 / 操作鼠标键盘 / 跑命令 / 读写文件 / Git 读写）；
- 负责人的申请会**转呈到你和主 Bot 的私聊**，你在那一处点就行，不用满群找卡片；
- 批准门槛按"批的是什么"分：只读的桌面上点一下就行，"能动手"的要手机；
  不用手机端可以在设置里打开「允许在本机批准」（会记审计，并写明代价）；
- 授权一条 bot 一条、绑当前规矩版本、到期自动失效，随时能在授权面板收回。

### 首次使用会看到一个授权页

第一次打开会先让你划定范围：这台机器上它能看见什么、项目的 Git 范围、哪些动作永远要你点头、
以及**它给不了的硬隔离保证**。选完会真的建出对应授权（不再是一张说明纸）。

### Git 更完整的权限

- 合并 / 变基 / 重置 / 清理这四种**可以用**了，但只给主 Bot 和负责人，而且必须手机确认；
- `reset` 只支持 `--soft` / `--mixed`（`--hard` 不提供），`clean` 默认只列出会删什么；
- 仓库路径必须落在你给的范围里：worktree 的共享元数据、外部对象库跑到外面就拒绝；
- 同一仓库的写入加锁，两个任务不会同时往一个 `.git` 里写。

### 收尾更干净

任务结束会自动回收：临时授权、后台进程、桌面租约。角色变更（主 Bot 被降级）会回收它的 host 授权；
启动时做一次授权对账（孤儿授权、错配收掉；资源跑到工作目录外的只提醒不自动撤）。

### 其它

- 第三方组件许可证清单（200 个组件，GPL/AGPL/未声明一律报错）；
- 台账自检脚本：文档里写的 commit 必须真的在历史里（这一版就抓出并修好了十来个过期状态）。

---

**已知限制**

- 独立桌面只对经典 Win32 应用可靠；现代合成应用可能截成黑图（会如实报失败，不会硬点）；
- macOS 没有等价的桌面隔离 API，那边只能走虚拟机；
- 任务系统（自动拆活/派活/验收）仍然默认关闭，测试覆盖还不够。
