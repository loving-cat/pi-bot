## ② 长版正文（小红书口吻，600 字以内）

以前用 AI，是我伺候它：一个提示词一个提示词地喂，来回粘上下文，它答完我还得自己动手跑命令、导表格、改文件。😮‍💨

现在我换了个用法：不喂提示词了，我派活。

手机里发一句"给这个项目做一次体检"，群里总经理拆活、部门老大接单、@成员各自去干。被 @ 的人同时开干，谁先干完谁先说话。中途我想改方向，直接插一句进去，它当场停下先报进度，再按新的做。💬

最爽的是它真动手。读写文件、跑命令、开局进程、调 MCP，读我发进去的 PDF 和 Excel，全是它自己来。跑完的图表、导出的表格直接落盘，作为附件回到我手机上——我不用再追着问"代码呢"。📎

手机上也是真的能用：服务端跑在我自己电脑上，手机连同一个局域网就行，中间没有云端。模型我自己配，任何兼容接口都能接。🔒

用了一阵子，最大的变化不是它变聪明了，是我不用再当"提示词搬运工"。它要是没出内容，会自己催一遍、换个模型补一段，实在不行才报错，不会甩我一片空白；卡住了会有人被通知去收尾。

现在它占了我一半的重复活。剩下那一半，是我还没想好怎么派。🚀

## 事实核对（每条卖点都对得上是 README 的哪一条）

| 文案里的说法 | README 依据 |
|---|---|
| 一群 agent、总经理拆活 / 部门老大接单 / @成员各自去干 | 「组织架构」表 + 「部门里的调度规则」：`@名字` 就是调度信号 |
| 被 @ 的人同时开干，谁先干完谁先说话 | 调度规则「全员并发」：有几个成员就几个并发，先后由老大定 |
| 中途插话，它停下先报进度再按新的做 | 「对话」→ 中途插话（`steer`）；调度规则「上级可以打断」 |
| 读写文件、跑命令、调 MCP，真动手 | 开篇：「底下是真正的 pi agent：能读写文件、跑命令、开子进程、调 MCP」 |
| 读发进去的 PDF / Excel | 「多模态」：解析 PDF / Excel / Word / HTML / CSV / MD / JSON |
| 图表和表格直接落盘，当附件发回手机 | 「多模态」：它画的图 / 导出的表格自动作为附件发回来 |
| 服务端跑在自己电脑上，手机连同一局域网，无云端 | 「快速开始 · 手机端」：没有云端中转，服务端就跑在你自己机器上 |
| 模型自己配，任何兼容接口都能接 | 「功能 · 运维」/「4. 配模型」：任何 OpenAI 兼容接口（baseUrl + key + 模型名） |
| 没出内容会自己催一遍、换模型补一段，不行才报错 | 「运维」：空回复自动兜底（催一次 → 切最稳模型补一段 → 都不行才报错） |
| 卡住了会有人被通知去收尾 | 调度规则「心跳看门狗」：收尾这一轮，把「这单断了」报给组长/主控 |
| Windows 解压双击就能开，安卓装个包 | 「下载」表：Windows 解压双击 `pi_bot.exe`；Android APK 直接装 |

**没写的东西**（README 里没有，或还没上线）：下载转化数据、多用户/团队协作、云端同步、
移动端也能当宿主、语音输入、任何"X 倍效率"之类的量化承诺。
