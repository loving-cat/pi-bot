# 应用连接

设置中的「应用连接」管理远程 MCP 服务、本地命令工具和本机已有配置。
搜索、分类、验证、启停和 Bot 分配在同一入口完成。系统接入与技能库保留各自入口。

## 使用流程

1. 选择远程服务或本地工具，填写地址或启动命令；凭据填写在请求头或环境变量。
2. 验证连接。客户端完成协议初始化和工具列表发现后显示「已验证可用」、时间和工具数量。
3. 保存配置，启用连接并分配给需要它的 Bot。负责人依照既有角色规则派给成员执行。
4. 在详情查看工具列表、重新验证、编辑或停用。

本机导入只读取已有配置并复制到本应用，之后独立管理。导入条目默认停用、待验证。
目录中的通用入口需要用户提供服务或已安装工具；本期不含品牌应用预设和浏览器账号授权。

## 状态与凭据

启用开关表示允许 Bot 使用，验证结果表示最近一次协议探测成功，两者分别显示。
探测后会释放连接和进程。配置变化、服务端重启或超过十分钟需要重新验证。
零工具表示协议可用但未发现业务工具，不能据此认定 Bot 已具备某项能力。

环境变量和请求头采用 AES-256-GCM 加密存储，公共接口和事件只返回键名及是否已保存。
编辑时未填写、空白或空对象保留已有凭据；「清除已保存凭据」明确清除，再应用本次填写值。
更改连接类型不沿用另一种类型的凭据。密钥不可用时拒绝凭据写入，保留原数据。
历史明文在密钥可用后整体迁移；迁移未完成时阻止再次明文保存。

服务地址中的账号口令、常见凭据查询参数及明确的凭据命令参数会被拒绝，应改放请求头或环境变量。
不要把凭据写入名称、描述或其他普通配置字段。

## 分配与审批

每个 Bot 最多分配二十个连接；批量分配先校验全部 Bot 与容量，再应用修改。
停用、更改配置或取消分配后，旧会话的外部工具调用也会被阻止。

部门规矩为「需批准」时，动态外部工具和资源操作均进入审批，不根据服务自报的只读标记跳过。
一次批准绑定会话、Bot、连接配置修订及调用参数；本任务授权也绑定连接配置修订。
审批摘要展示工具名，不保存可能含凭据的原始外部调用参数。
「只读」仍禁止 MCP；「允许」保留原有含义。

## 接口与模块

| 接口 | 用途 |
|---|---|
| `GET /api/connections` | 目录、脱敏连接、验证结果与 Bot 分配 |
| `POST /api/connections/:id/verify` | 验证已保存配置 |
| `PUT /api/connections/:id/bots` | 原子校验后替换分配，正文为 `botIds` |
| `/api/mcp`、`/api/mcp/:id` | 创建、编辑和删除，保持既有入口 |
| `POST /api/mcp/test` | 草稿验证，不保存配置 |
| `/api/local-capabilities`、`/api/local-capabilities/import` | 脱敏扫描与服务端导入 |

所有接口沿用既有鉴权。草稿和保存验证共享并发上限；单次验证有超时、响应体积、分页及工具数量上限。
HTTP 支持有界 JSON/SSE，固定已校验的直连地址，不跟随重定向转发凭据；代理失败不回退裸连接。
本地命令复用跨平台启动方式，验证结束回收本次进程树。

## 验证

后端专项：`node tests/mcp-credentials.mjs`、`node tests/mcp-probe.mjs`、`node tests/connections.mjs`，均纳入 `tests/all.mjs`。
客户端专项：`flutter test test/connections_test.dart`。
测试使用合成工具、随机本地端口和隔离数据，不需要真实账号或模型。
原生预览入口为 `flutter run -d macos -t tool/connections_gallery.dart`，只使用内存合成数据，
不调用应用初始化、本机配置扫描或真实服务。
后续新增具体应用时，仍须逐项验证服务兼容性、授权条件和真实业务操作。

## 当前边界

真实业务调用仍由既有会话运行时连接服务。探测使用的地址固定与重定向限制只约束验证请求，
不等于业务调用已经放进网络沙箱。连接中心应配置可信来源的服务；执行期统一传输控制需单独扩展。
工具能力由服务提供方决定，协议验证成功不保证每次业务调用成功。
