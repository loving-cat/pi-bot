# 规格：Grok 风格形象与丝滑交互（SPEC-MOTION-V1）

> 适用范围：`app/lib/` 前端渲染与交互层；严格遵守「交互/输出时 60～120fps 丝滑，静止 6 秒归零 0 Ticker，禁用离屏 `saveLayer` 与模糊滤镜」的硬件性能红线。

### 1.2 体积守恒果冻物理与歪头联动

1. **可见呼吸律动**：上下浮动幅值为 `0.010 * side`，伴随 `0.012` 体积守恒拉伸（`scaleX = s`, `scaleY = 1 / s`）与 `±0.020 rad` 轻摇（`phase == 0` 时完全退回静止造型）。
2. **视线—歪头耦合**：水平视线转动 `yaw` 时叠乘 `-yaw * 0.10` 的倾斜 `roll`，消除刚性平移感。
3. **欠阻尼果冻回弹（Poke）**：点击头像触发约 520ms 的欠阻尼正弦挤压回弹，伴随短暂开心弯眼反馈。
4. **自然双眨眼**：正常间隔 `2.6s～6.8s` 单眨，约 `22%` 概率连眨两次（中间隔 `70ms`）。

### 1.3 五态微表情（`AvatarMood`）

| 状态 | 眼型与视线 | 休眠策略 |
|---|---|---|
| `idle` | 标准胶囊眼，自然眨眼，悬停随指针 | 无交互 6 秒后停表休眠 |
| `listening` | 眼神略聚焦微垂（倾听打字），呼吸保持平稳 | 停止输入 2.5 秒恢复 `idle`，6 秒休眠 |
| `busy` | 眼神微眯（`0.93x`）略抬，定期左右搜寻扫视 | 持续激活不休眠 |
| `speaking` | 眼神透亮略睁（`1.04x`），呼吸周期加快至 `5.5s` | 持续激活不休眠 |
| `happy` | 20px 以上切换柔弧弯眼 `^ ^`（小尺寸微眯保清晰） | 回复完成或戳中瞬间展示，随后回归休眠节奏 |

## 二、Grok 风格流式渲染引擎

### 2.1 自适应追字缓冲（`StreamingMarkdownView`）

- 服务端每次推入全量增量快照时，按帧驱动单个按需 `Ticker` 追赶显示文本，速率为 `max(55, backlog * 16)` 字符/秒，积压多时自动加速追平而不拖慢结束时机。
- 推进切分点时跳过 UTF-16 高代理项（`0xD800..0xDBFF`）前边界，保证 emoji 等多码点字符零截断、零乱码。
- 追平目标长度后 `Ticker` 立即休眠；测试环境与关闭动画开关时直出完整文本，零挂起帧。

### 2.2 独立语法外呼吸尾标（`MdText.streamingCursorColor`）

- 流式尾标 `'▍'` 不再拼接入原始 Markdown 字符串，先对纯净文本解析 Markdown 语法块（防止未闭合代码块/加粗语法被尾部光标污染），再将带动态呼吸透明度（`0.28..0.95`）的 `'▍'` 挂入最后一个渲染文本块的末尾 `TextSpan`。

## 三、思考流光与零跳变容器过渡

- **金属流光扫掠（`ThinkingShimmer`）**：单层 `ShaderMask` 线性渐变（周期 `1600ms`，零高斯模糊），作用于运行中的 `ActivityMonitor` 与 `ToolSteps` 文案；未启用或测试关闭动画时零控制器开销、零帧损耗。
- **平滑过渡**：`ToolSteps` 展开区启用 `AnimatedSize`（`200ms`，`Cubic(0.22, 1, 0.36, 1)`）；`_RoundButton` 增加细腻按压弹性微缩放且保持外框几何尺寸恒定。

## 四、模型组精简辨识规范（`compactModelDisplay`）

1. **剥除冗余路由**：自动去掉 `accounts/.../models/`、`publishers/.../models/`、`models/` 及常见厂商前缀，并去除末尾日期快照后缀（如 `-20250514`、`@20250514`、`2025-05-14`）；模型组中有更清晰的可读 `name` 时优先展示。
2. **组简称消歧**：剥除模型组名末尾的「模型组 / 分组 / 渠道 / 服务商 / Provider / Group / API」等泛词并紧凑显示；若不同 `groupId` 折叠出相同简称，自动保留差异尾字或追加短标识，确保不同模型组下的同名模型在侧边栏徽章、成员列表与模型选择器中**一眼可区分、绝不重名**。
