# HTML 附件预览

HTML/HTM 附件在文件弹窗中默认展示报告，可切换源码、放大、下载或使用系统程序打开。
一期支持 UTF-8 单文件、内嵌样式、普通 DOM 交互和 data 图片。需要额外文件、网络接口、
CDN 脚本、嵌套网页、Web Components 或工作线程的文档不属于本期支持范围。

## 加载与界面

- App 自己读取附件，渲染层仅接收正文，不接收附件地址、token、Cookie 或业务状态。
- 最多完整读取 1 MiB；构造出的宿主文档上限 2 MiB。超限直接提示下载，不截断后渲染。
- 不跟随附件响应重定向；失败、无效编码、取消和超时使用固定提示，不回显带凭据的 URL。
- 源码视图可选择复制，过长时明确标记显示范围。切换到源码、打开宿主链接对话框或关闭
  弹窗会销毁 WebView；重新预览会重建，因此报告内的临时筛选状态会重置。
- 外链从静态 HTML 中提取，仅接受受限的公共 HTTPS 地址；用户在宿主列表确认后才打开。
  报告脚本和页面导航不能自动启动浏览器。

## 渲染边界

可信宿主壳以编码数据承载报告，报告放在只有 `allow-scripts` 的独立 srcdoc 子帧中。
不授予 same-origin、forms、popups、downloads 或 top-navigation。保护初始化成功后才插入
报告 DOM 并重建内联脚本；失败则保持关闭并回退源码。

壳与报告分别设置 CSP，限制网络、框架、工作线程、对象、基础地址和表单；只允许必要的
内联脚本/样式及 data 图片和字体。静态嵌入上下文、远程脚本、预连接提示会被移除。
文档开始前限制网络构造器、网页桥、打印和创建新活动文档的入口，并固定防护依赖的引用。
这些限制不代替平台资源与导航控制。

- macOS 使用非持久 WebKit 存储和原生内容规则；协议规则分别声明，不使用其不支持的
  正则分支语法。原生消息桥关闭，不尝试改写引擎只读的 WebKit 命名空间。
- Windows 使用独立临时 WebView2 环境，拦截所有网络/文件资源，默认拒绝导航、权限、
  下载和新窗口。禁用桥脚本注入并保留网页侧能力限制；底层消息入口仍有每视图凭据校验，
  不描述成整个原生消息入口已删除。
- 初始化、加载和资源释放有上限；取消后晚到的环境会释放，旧页面不会更新新页面状态。

依赖固定为 `flutter_inappwebview 6.2.0-beta.3`，用于原生消息桥关闭 API。升级插件或运行
引擎后须重新验证平台行为。缺少 WebView2 或初始化失败时显示源码/下载入口。
`ready` 只表示页面装载完成，不保证任意用户脚本无错误或异步模块已完成。

服务器附件接口继续使用下载响应和限制性 CSP，现有鉴权与本机信任规则不因预览放宽。

## 模块

| 文件 | 职责 |
|---|---|
| `html_preview_loader.dart` | HTML 识别、有界读取、解码、取消和错误分类 |
| `html_preview_document.dart` | HTML 解析、隔离壳、脚本与外链整理 |
| `html_preview_platform_policy.dart` | 平台策略、导航/外链判定 |
| `html_preview_environment.dart` | 环境所有权、晚到结果和幂等释放 |
| `widgets/offline_html_view.dart` | 原生 WebView、初始化与生命周期 |
| `widgets/html_attachment_preview.dart` | 预览/源码及宿主确认界面 |

## 验证

`flutter test` 包含加载、文档构造、平台策略、生命周期和界面回归。
`tool/html_preview_gallery.dart` 默认提供仅含合成报告的手动验收入口。
使用 `PI_BOT_HTML_QA=true` 构建时，程序自动检查正常报告、离线资源、404、超限、超时，
将固定布尔结果写入 `PI_BOT_HTML_QA_OUTPUT` 后退出。此编译开关只用于测试构建，
生产构建不包含测试结果通道。测试不读取用户配置，不连接模型，且只使用本次随机回环端口。

原生验收同时检查功能可用和网页资源请求为零；不能把 Flutter 组件测试或策略配置存在
当作平台原生验证通过。测试 App 使用独立名称和标识，结束后注销并删除。
