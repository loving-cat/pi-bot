# pi-bot v1.4.1

这一版几乎全是**"bot 别打扰我"**的修补 —— 每一条都来自你用的时候踩到的东西。

## 1. 调研不再把浏览器弹到你脸上

之前让它调研一件事（比如 xAI 的接口细节），屏幕上会弹出一个浏览器窗口，
页面你还点不动 —— 底下挂着 "Agent is in control"。

根因是**工具缺了一档**：

| 需求 | 之前能用 | 问题 |
|---|---|---|
| 只要 HTML | `web_fetch` | 没有 JS、没有登录态 |
| 要 JS + 登录态 | **只有 ego** | 窗口就在你屏幕上 |
| 岛（另一张桌面） | 有窗口你看不见 | **只能靠窗口消息驱动** —— Chromium 自绘，点不到 DOM |

补上中间那一档：**`browser_research`**。
在独立桌面上起一个**真 Chromium**（不是无头解析器，不会被站点识别），
控制走 CDP（走 TCP，跟桌面无关），登录态用你浏览器配置的**副本**（不同步回本机）。

- `open` 返回标题 + 正文开头；`eval` 跑 JS 拿结构化数据；`shot` 截图；`close` 收摊；
- 默认 `mode: island`（另一张桌面上的真窗口）；`mode: headless` 更省，但部分站点会识别；
- 提示词明确改了：**调研不许用 ego**。

另外 ego 收尾现在会**交还控制权**（只对"agent 正在控制"的空间，已经是你的一个都不碰），
并且服务端强制退出全屏兜底 —— 收摊后你看到的是能点、能拖、Esc 能退的普通窗口。

## 2. 长期授权不再随重启消失

「世代」（这次开机的编号）只该管**任务级临时授**。之前的 bug 是把世代也打在了
长期授权上，于是**重启一次全灭**，用户还得重新批一遍。

现在：长期授权不带世代；启动时清一遍历史遗留的世代标记（本机验证 98 条授权、0 条带世代）；
任务级授权仍然一次一换 —— 卡死重启就等于一次强制重置。

## 3. 简单的事自己做，别派

"打开 B 站热门第一条"这种事之前会被派给别的 bot。提示词加了硬规矩：

> 1~3 步能做完（打开页面 / 播放视频 / 看一眼 / 改一个文件 / 跑一条命令）→ 自己做；
> 需要同时推进两件事、需要专门角色、或活本身很大 → 才派。
> 判据一句话：**这件事要不要两个人在同一时间干？**

## 4. 派活的结果落到派活房间

成员在私聊里干活的过程（"我来看看这个函数"）不再推给你；
结果回到**你派活的那个房间**，过程留在成员自己的会话里。

## 5. 无边框窗口的逃生口

App 是无边框的，之前没有"退出"的常规路径。

- `Esc`：关最上一层（弹窗 / 面板），没有可关的就什么都不做；
- `Ctrl+Shift+Q`（macOS `⌘+Shift+Q`）：退出应用。

## 6. 用户习惯（P0）

偏好记忆按**话题**去重（新说法覆盖旧说法，不是越攒越多），
提示词里最多带 5 条（强/弱两档）。"以后都这样"这句话现在真的会被记住。

## 7. 桌面审批：只读的可以就地批，"能动手的"仍要手机

`desktop.input` / `cmd.exec` / `file.write` / `git.commit` 这类要动你机器的，
默认仍然只能手机批（除非你自己打开 `allowLocalApproval`，且会记审计、标 `channelWeakened`）。

## 修掉的其他问题

- CDP 回包必须**按 id 对**：事件和回包混在一条流里，按顺序取会拿到事件然后永远等；
- 截图对"非活动页"会报 `-32000`：先 `bringToFront`，失败再退一步只截视口；
- `Page.navigate` 不等于文档解析完：现在轮询 `document.readyState` 到 `complete`
  （这个 bug 是 CI 抓出来的 —— 本地靠时序侥幸通过）；
- 收无头浏览器时 Windows 上要 `taskkill /T` 杀整棵树，否则孤儿进程占住 profile，
  下一次同一个 bot 就起不来。
